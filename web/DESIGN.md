# Sentinel 디자인 기준

화면을 추가·수정할 때 따르는 시각 규칙. 참고: getdesign.md의 Sentry 분석(2026-09-26 확인). 마케팅 요소(마스코트, 별 배경, 전용 제목 폰트, 대문자 버튼)는 제외하고 제품 화면에 필요한 부분만 채택

## 원칙

- 두 가지 바탕: 메뉴 영역은 짙은 보라, 표·로그·폼이 있는 본문은 흰색. 촘촘한 데이터는 항상 밝은 바탕에서 읽음
- 강조는 하나: 칠한 버튼(주 버튼)은 화면당 1개. 나머지는 테두리 버튼·글자 버튼으로 한 단계 낮춤
- 색은 의미가 있을 때만: 통과·실패·오류·진행 상태 색 외의 색은 최소화. 라임은 표시(로고, 현재 메뉴)에만 사용
- 라이트 모드만 지원. 다크 모드는 별도 작업

## 색

`app/globals.css`의 `:root` 토큰. 컴포넌트는 토큰 이름으로만 참조

| 토큰 | 값 | 용도 |
|------|----|------|
| `--sidebar` | `#1f1633` | 사이드바 바탕 (Sentry Ink Violet) |
| `--sidebar-border` | `#362d59` | 사이드바 구분선 |
| `--sidebar-foreground` | 흰색 72% | 사이드바 글자 |
| `--sidebar-accent` | 흰색 10% | 사이드바 항목 강조 바탕 (현재 메뉴, 마우스 오버) |
| `--sidebar-primary` | `#c2ef4e` | 현재 메뉴 표시선, 로고 점 (Electric Lime) |
| `--primary` | `#150f23` | 주 버튼 (Midnight Violet) |
| `--primary-raised` | `#2a2140` | 주 버튼에 붙는 보조 영역 (실행 버튼 옆 환경 선택) |
| `--foreground` | `#1f1633` | 본문 글자 |
| `--muted-foreground` | `#6b6478` | 보조 글자. 흰 바탕 대비 5.7:1 |
| `--muted` / `--accent` | `#f6f5f9` / `#f1eef8` | 표 머리·마우스 오버 바탕 |
| `--border` / `--input` | `#e5e7eb` / `#cfcfdb` | 카드·표 테두리 / 입력칸 테두리 |
| `--ring` | `#3b82f6` | 키보드 포커스 (유일한 파랑). 흰 바탕 대비 3.7:1. Sentry 원본 `#9dc1f5`는 1.9:1이라 한 단계 진하게 |
| `--brand-violet` | `#6a5fc1` | 링크 강조, HTTP 메서드 표시 |
| `--brand-violet-soft` | `#ece9f5` | HTTP 메서드 배지 바탕 |

- 상태 색(통과 초록·실패 빨강·오류 주황·진행 파랑)은 기존 값 유지. 라임·보라와 겹치지 않음
- Sentry의 분홍(`#fa7faa`)은 실패 빨강과 혼동되어 미사용
- 차트 계열 색(`--chart-series-*`)과 변화 표시 색(`--delta-*`)은 기존 검증 값 유지

## 글꼴

- 본문·제목: Pretendard Variable (한글·영문 공통). `pretendard` 패키지의 동적 서브셋을 자체 배포하여 쓰인 글자 범위만 내려받음 (CSP `font-src 'self'` 유지)
- 코드·경로·시각·상태 코드: Geist Mono
- 크기: 화면 제목 24px/600(자간 -0.4px), 구획 제목 16px/600, 본문 14px, 보조 13px, 표 머리 12px/500

## 배치

- 넓은 화면(`md` 768px 이상): 왼쪽 고정 사이드바(너비 224px) + 본문(최대 1152px)
- 좁은 화면: 위쪽 막대(로고, 메뉴 버튼). 메뉴 버튼으로 사이드바를 서랍처럼 열기
- 로그인·초대·재설정 화면: 사이드바 없이 짙은 보라 바탕 가운데 흰 카드

## 버튼 배치

| 위치 | 규칙 |
|------|------|
| 화면 머리 오른쪽 | 그 화면의 핵심 동작 1개를 주 버튼으로. 보조 이동(예: 실행 이력)은 테두리 버튼 |
| 화면 단위 수정·삭제 | 머리 오른쪽 끝 "⋯" 메뉴 안. 삭제는 구분선 아래 빨간 글자, 확인 창 필수 |
| 구획 머리 | 추가 동작은 제목과 같은 줄 오른쪽 테두리 버튼. 부수 동작(가져오기 등)은 글자 버튼 |
| 표의 행 | 연필·휴지통 아이콘 대신 행 끝 "⋯" 메뉴 하나. 이름 링크가 기본 동작 |
| 대화상자 | 오른쪽 정렬, 왼쪽 취소·오른쪽 확인 |

- "⋯" 메뉴 버튼의 접근 이름은 대상 포함 (예: "환경 self 작업")
- 파괴적 동작은 항상 메뉴 안쪽 마지막, 바로 누르는 버튼으로 두지 않음

## 모양

- 모서리: 버튼·입력칸 8px(`rounded-lg`), 카드·표 테두리 약 11px(`rounded-xl`), 배지 약 5px(`rounded-sm`, 상태 배지는 둥근 알약)
- 그림자: 떠 있는 요소(메뉴, 대화상자)에만. 카드는 테두리만
- 표: 머리 행은 옅은 보라 회색 바탕, 행 구분선 1px, 마우스 오버 시 바탕 강조
