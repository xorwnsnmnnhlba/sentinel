# Sentinel 디자인 기준

화면을 추가·수정할 때 따르는 시각 규칙. 방향은 관제 화면(Grafana·Datadog 같은 모니터링 도구): 어두운 바탕 기본, 숫자·상태가 먼저 보이고, 장식 없이 조밀하게 (2026-10-03 변경. 이전의 Sentry 참고 보라·라임 디자인은 범용 생성 화면처럼 보여 교체)

## 원칙

- 무채색 흑연 바탕: 사이드바가 가장 어둡고, 본문 바탕 위에 패널이 한 단계 밝게 놓임. 사이드바는 두 테마 공통
- 색은 의미가 있을 때만: 통과·실패·오류·진행 상태 색과 변화(좋아짐·나빠짐) 외에는 무채색. 링크 강조·HTTP 메서드만 청록
- 설명 문장을 두지 않음: 화면·구획 제목 아래 회색 설명 문장 금지. 값을 읽는 데 필요한 기간·기준·건수만 패널 머리 오른쪽에 짧게(고정폭 글꼴). 확인 창의 결과 안내(예: "실행 이력은 유지됩니다")는 유지
- 숫자는 고정폭: 실행 수·통과율·시각·응답시간은 Geist Mono + tabular-nums
- 강조는 하나: 칠한 버튼(주 버튼)은 화면당 1개. 나머지는 테두리 버튼·글자 버튼. 다크에서는 반전(밝은 바탕 + 짙은 글자)

## 테마

- 다크(기본)·라이트·시스템 설정 중 선택. 사이드바 아래 테마 버튼, 쿠키 `sentinel_theme`(1년)에 저장. 고르지 않았거나 알 수 없는 값이면 다크
- 서버가 쿠키로 `<html data-theme>`를 정해 렌더링. 첫 화면부터 선택한 테마이며 테마용 인라인 스크립트 없음 (CSP 유지)
- 토큰은 `light-dark(라이트, 다크)` 하나로 정의하고 `data-theme`별 `color-scheme`(system은 `light dark`)으로 결정. 스크롤바·날짜 입력 같은 기본 컨트롤도 함께 전환
- `dark:` 변형은 다크 선택 시, 또는 시스템 설정에서 운영체제가 다크일 때 적용 (`@custom-variant dark`)
- 컴포넌트 기본 스타일의 `dark:` 클래스가 직접 지정한 토큰 색을 덮을 수 있음. 바탕색을 바꾼 컴포넌트는 `dark:` 값도 함께 지정 (예: 실행 버튼 옆 환경 선택)

## 색

`app/globals.css`의 `:root` 토큰. 컴포넌트는 토큰 이름으로만 참조. 대비는 해당 테마의 본문 바탕 기준

| 토큰 | 라이트 | 다크 | 용도 |
|------|--------|------|------|
| `--sidebar` | `#0a0c0f` | 같음 | 사이드바 바탕 (가장 어두운 흑연) |
| `--sidebar-border` | `#1d2229` | 같음 | 사이드바 오른쪽 선·구분선 |
| `--sidebar-foreground` | 흰색 68% | 같음 | 사이드바 글자. 대비 9.1:1 |
| `--sidebar-accent` | 흰색 8% | 같음 | 사이드바 항목 강조 바탕 (현재 메뉴, 마우스 오버) |
| `--sidebar-primary` | `#e3e6ea` | 같음 | 현재 메뉴 표시선 |
| `--background` | `#f3f4f6` | `#0c0e12` | 본문 바탕 |
| `--card` / `--popover` | `#ffffff` | `#12151a` / `#181c22` | 패널 / 메뉴·대화상자 |
| `--primary` | `#14171c` | `#e3e6ea` | 주 버튼 (다크는 반전) |
| `--primary-raised` | `#2b3139` | `#c4c9d0` | 주 버튼에 붙는 보조 영역 (실행 버튼 옆 환경 선택) |
| `--foreground` | `#14171c` | `#e3e6ea` | 본문 글자. 패널 대비 18.0:1 / 14.6:1 |
| `--muted-foreground` | `#59606a` | `#8f97a1` | 보조 글자. 패널 대비 6.4:1 / 6.2:1, 가장 밝은 강조 바탕 위 5.4:1 |
| `--muted` / `--accent` | `#f1f3f5` / `#eaedf1` | `#171b21` / `#1d2229` | 표 머리·마우스 오버 바탕 |
| `--border` / `--input` | `#dde1e6` / `#9aa3ae` | `#262c35` / `#4b5461` | 패널·표 선 / 입력칸 테두리 |
| `--ring` | `#2563eb` | `#6ea8fe` | 키보드 포커스. 패널 대비 5.2:1 / 7.6:1 |
| `--destructive` | `#b42318` | `#f2827a` | 삭제·오류 문구. 옅은 빨강 배지 위에서도 4.5:1 이상 |
| `--brand` | `#0b6c86` | `#5cc6dd` | 링크 강조 (청록, 상태 색과 겹치지 않음) |
| `--brand-soft` / `-deep` | `#e0f1f6` / `#0a4a5c` | `#10303a` / `#a8e5f2` | HTTP 메서드 배지 바탕 / 글자 (대비 8.4:1 / 10.1:1) |
| `--meter-track` | `#cde2fb` | `#20335a` | 통과율 막대 빈 부분. 채움과 대비 3:1 이상 |

- 상태 색(통과 초록·실패 빨강·오류 주황·진행 파랑)은 Tailwind 팔레트. 라이트는 800 단계 글자(회색 본문 바탕 위 옅은 배지에서도 4.5:1), 다크는 400 단계
- 차트 계열 색(`--chart-series-*`)과 변화 표시 색(`--delta-*`)은 기존 검증 값 유지. 다크 값은 어두운 바탕 대비 4.9:1 이상

## 접근성 검사

- `e2e/accessibility.spec.ts`: axe-core로 WCAG 2.2 A·AA 규칙과 권장 규칙(제목 순서, 랜드마크 등)을 라이트·다크 모두에서 검사. 대상은 주요 화면, 열린 메뉴·대화상자(삭제 확인, 스케줄, 문서 가져오기, 환경 수정, 등록, 초대), 좁은 화면 메뉴 서랍
- 글자 대비 기준: 본문 4.5:1, 큰 글자 3:1
- 제목은 단계를 건너뛰지 않음 (h1 → h2 → h3). 펼침 목록(Accordion)의 항목 제목은 h3이므로 위에 h2 구획 제목 필요 (예: 실행 상세의 "케이스별 결과")
- 허용한 위반은 `e2e/fixtures.ts`의 `ACCEPTED`에 규칙·선택자·사유로 기록. 현재 1건: 떠 있는 "⋯" 메뉴가 랜드마크 밖에 그려지는 것(region)
- 강조를 낮출 때 투명도(`opacity`) 대신 보조 색 토큰 사용. 투명도는 글자와 바탕을 함께 흐리게 하여 대비가 쉽게 미달 (예: 실행 결과의 0건 배지는 `bg-muted text-muted-foreground`)
- 비활성 컨트롤(disabled)은 WCAG 대비 기준 제외 대상이라 검사하지 않음
- 화면·색을 추가하면 검사 대상 경로에도 추가

## 글꼴

- 본문·제목: Pretendard Variable (한글·영문 공통). `pretendard` 패키지의 동적 서브셋을 자체 배포하여 쓰인 글자 범위만 내려받음 (CSP `font-src 'self'` 유지)
- 코드·경로·시각·상태 코드: Geist Mono
- 이름 표기: "SENTINEL" 고정폭 대문자(CSS `uppercase`, 읽기 도구에는 "Sentinel"), 자간 0.2em, 점·아이콘 장식 없음
- 크기: 화면 제목 20px/600, 패널 제목 14px/600, 본문 14px, 보조·보조 정보 12px, 요약 숫자 30px 고정폭

## 배치

- 넓은 화면(`md` 768px 이상): 왼쪽 고정 사이드바(너비 224px, 오른쪽 선) + 본문(최대 1536px)
- 좁은 화면: 위쪽 막대(이름 표기, 메뉴 버튼). 메뉴 버튼으로 사이드바를 서랍처럼 열기
- 로그인·초대·재설정 화면: 사이드바 없이 흑연 바탕 가운데 패널
- 패널 사이 간격 16px. 대시보드는 위에서부터 알림성 패널(점검 중·진행 중·모니터링 공백, 있을 때만) → 요약 막대 → 스위트별 통과율 → 2열(최근 실패·응답시간 악화) → 불안정 케이스

## 패널

`components/catalog/section.tsx`의 `Panel`. 화면의 구획은 모두 패널로

- 머리 막대: 왼쪽 제목(h2)·건수(고정폭, 옅게), 오른쪽 보조 정보(`meta`, 고정폭 12px)와 동작 버튼. 아래 1px 선
- 본문: 표는 테두리 없이 바로, 그 외 내용은 여백(`p-4`)과 함께. 빈 상태는 `PanelEmpty`
- 요약 수치는 패널 대신 칸을 세로선으로 나눈 한 줄 막대 (3칸 카드를 따로 띄우지 않음)
- 목록 화면(실행 이력·변경 이력·검색·프로젝트·사용자): 위에 조건 막대(있으면), 아래 결과 패널. 전체 건수·정렬은 패널 머리 `meta`, 페이지 이동은 패널 아래 막대(`PanelFooter`)
- 행 전체를 누르는 목록은 이름 링크를 행 전체 클릭 영역으로 확장 (`after:absolute after:inset-0`)
- 건수는 제목과 공백으로 구분되어 읽기 도구에 "검색 결과 3"으로 전달
- 패널 밖에 단독으로 놓는 표·빈 상태는 `TableFrame`·`Empty`

## 버튼 배치

| 위치 | 규칙 |
|------|------|
| 화면 머리 오른쪽 | 그 화면의 핵심 동작 1개를 주 버튼으로. 보조 이동(예: 실행 이력)은 테두리 버튼 |
| 화면 단위 수정·삭제 | 머리 오른쪽 끝 "⋯" 메뉴 안. 삭제는 구분선 아래 빨간 글자, 확인 창 필수 |
| 구획 머리 | 추가 동작은 제목과 같은 줄 오른쪽 테두리 버튼. 부수 동작(가져오기 등)은 글자 버튼 |
| 표의 행 | 연필·휴지통 아이콘 대신 행 끝 "⋯" 메뉴 하나. 이름 링크가 기본 동작 |
| 대화상자 | 오른쪽 정렬, 왼쪽 취소·오른쪽 확인 |

- "⋯" 메뉴 버튼의 접근 이름은 대상 포함 (예: "환경 self 작업")
- 파괴적 동작은 항상 메뉴 안쪽 마지막, 바로 누르는 버튼으로 두지 않음

## 모양

- 모서리: 작게. 버튼·입력칸 4px(`rounded-lg`, `--radius` 0.25rem), 패널 약 4px, 배지 약 2.4px. 통과율 막대는 각진 막대
- 그림자: 떠 있는 요소(메뉴, 대화상자)에만. 패널은 테두리만
- 커서: 누를 수 있는 요소(버튼·메뉴 항목·탭·스위치·선택 상자·체크박스와 그 라벨·파일 선택)는 손가락. `app/globals.css` base 층에서 한 번에 지정하므로 컴포넌트에 `cursor-pointer`를 따로 달지 않음. 비활성 요소는 제외
- 표: 머리 행은 옅은 회색 바탕, 행 구분선 1px, 마우스 오버 시 바탕 강조
