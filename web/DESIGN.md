# Sentinel 디자인 기준

화면을 추가·수정할 때 따르는 시각 규칙. 참고: getdesign.md의 Sentry 분석(2026-09-26 확인). 마케팅 요소(마스코트, 별 배경, 전용 제목 폰트, 대문자 버튼)는 제외하고 제품 화면에 필요한 부분만 채택

## 원칙

- 두 가지 바탕: 메뉴 영역은 짙은 보라, 표·로그·폼이 있는 본문은 흰색(다크: 사이드바보다 한 단계 어두운 보라 검정). 사이드바는 두 테마 공통
- 강조는 하나: 칠한 버튼(주 버튼)은 화면당 1개. 나머지는 테두리 버튼·글자 버튼으로 한 단계 낮춤. 다크에서는 Sentry처럼 반전(밝은 바탕 + 짙은 글자)
- 색은 의미가 있을 때만: 통과·실패·오류·진행 상태 색 외의 색은 최소화. 라임은 표시(로고, 현재 메뉴)에만 사용

## 테마

- 시스템 설정(기본)·라이트·다크 중 선택. 사이드바 아래 테마 버튼, 쿠키 `sentinel_theme`(1년)에 저장
- 서버가 쿠키로 `<html data-theme>`를 정해 렌더링. 첫 화면부터 선택한 테마이며 테마용 인라인 스크립트 없음 (CSP 유지)
- 토큰은 `light-dark(라이트, 다크)` 하나로 정의하고 `data-theme`별 `color-scheme`(system은 `light dark`)으로 결정. 스크롤바·날짜 입력 같은 기본 컨트롤도 함께 전환
- `dark:` 변형은 다크 선택 시, 또는 시스템 설정에서 운영체제가 다크일 때 적용 (`@custom-variant dark`)
- 컴포넌트 기본 스타일의 `dark:` 클래스가 직접 지정한 토큰 색을 덮을 수 있음. 바탕색을 바꾼 컴포넌트는 `dark:` 값도 함께 지정 (예: 실행 버튼 옆 환경 선택)

## 색

`app/globals.css`의 `:root` 토큰. 컴포넌트는 토큰 이름으로만 참조. 대비는 해당 테마의 본문 바탕 기준

| 토큰 | 라이트 | 다크 | 용도 |
|------|--------|------|------|
| `--sidebar` | `#1f1633` | 같음 | 사이드바 바탕 (Sentry Ink Violet) |
| `--sidebar-border` | `#362d59` | 같음 | 사이드바 구분선 |
| `--sidebar-foreground` | 흰색 72% | 같음 | 사이드바 글자 |
| `--sidebar-accent` | 흰색 10% | 같음 | 사이드바 항목 강조 바탕 (현재 메뉴, 마우스 오버) |
| `--sidebar-primary` | `#c2ef4e` | 같음 | 현재 메뉴 표시선, 로고 점 (Electric Lime) |
| `--background` | `#ffffff` | `#110c1c` | 본문 바탕 |
| `--card` / `--popover` | `#ffffff` | `#181226` / `#1f1832` | 카드 / 메뉴·대화상자 |
| `--primary` | `#150f23` | `#f4f2fa` | 주 버튼 (Midnight Violet, 다크는 반전). 글자 대비 18.7:1 / 16.8:1 |
| `--primary-raised` | `#2a2140` | `#d6d0e4` | 주 버튼에 붙는 보조 영역 (실행 버튼 옆 환경 선택) |
| `--foreground` | `#1f1633` | `#ece9f3` | 본문 글자. 대비 17.2:1 / 16.0:1 |

| `--border` / `--input` | `#e5e7eb` / `#cfcfdb` | `#2e2645` / `#463d60` | 카드·표 테두리 / 입력칸 테두리 |

| `--destructive` | `#c3281b` | `#f38a81` | 삭제·오류 문구. 다크 대비 8.0:1 (빨간 틴트 버튼 위 5.0:1) |
| `--brand-violet` | `#6a5fc1` | `#a79ff0` | 링크 강조 |
| `--brand-violet-soft` / `-deep` | `#ece9f5` / `#422082` | `#2c2350` / `#d9d3fb` | HTTP 메서드 배지 바탕 / 글자 (대비 10:1 내외) |
| `--meter-track` | `#cde2fb` | `#20335a` | 통과율 막대 빈 부분. 채움과 대비 3.3:1 / 3.4:1 |

- 상태 색(통과 초록·실패 빨강·오류 주황·진행 파랑)은 기존 값 유지 (다크는 Tailwind 400 단계). 라임·보라와 겹치지 않음
- Sentry의 분홍(`#fa7faa`)은 실패 빨강과 혼동되어 미사용
- 차트 계열 색(`--chart-series-*`)과 변화 표시 색(`--delta-*`)은 기존 검증 값 유지. 다크 값은 어두운 바탕 대비 4.9:1 이상

## 접근성 검사

- `e2e/accessibility.spec.ts`: axe-core로 WCAG 2.2 A·AA 규칙과 권장 규칙(제목 순서, 랜드마크 등)을 라이트·다크 모두에서 검사. 대상은 주요 화면, 열린 메뉴·대화상자(삭제 확인, 스케줄, 문서 가져오기, 환경 수정, 등록, 초대), 좁은 화면 메뉴 서랍
- 글자 대비 기준: 본문 4.5:1, 큰 글자 3:1
- 제목은 단계를 건너뛰지 않음 (h1 → h2 → h3). 펼침 목록(Accordion)의 항목 제목은 h3이므로 위에 h2 구획 제목 필요 (예: 실행 상세의 "케이스별 결과")
- 허용한 위반은 `e2e/fixtures.ts`의 `ACCEPTED`에 규칙·선택자·사유로 기록. 현재 1건: 떠 있는 "⋯" 메뉴가 랜드마크 밖에 그려지는 것(region)
- 강조를 낮출 때 투명도(`opacity`) 대신 보조 색 토큰 사용. 투명도는 글자와 바탕을 함께 흐리게 하여 대비가 쉽게 미달 (예: 실행 결과의 0건 배지는 `bg-muted text-muted-foreground`)
- 비활성 컨트롤(disabled)은 WCAG 대비 기준 제외 대상이라 검사하지 않음
- 화면·색을 추가하면 검사 대상 경로에도 추가

## 글꼴

- 본문·제목: Pretendard Variable (한글·영문 공통). `pretendard` 패키지의 동적 서브셋을 자체 배포하여 쓰인 글자 범위만 내려받음 (CSP `font-src 'self'` 유지)
- 코드·경로·시각·상태 코드: Geist Mono
- 크기: 화면 제목 24px/600(자간 -0.4px), 구획 제목 16px/600, 본문 14px, 보조 13px, 표 머리 12px/500

## 배치

- 넓은 화면(`md` 768px 이상): 왼쪽 고정 사이드바(너비 224px) + 본문(최대 1152px)
- 좁은 화면: 위쪽 막대(로고, 메뉴 버튼). 메뉴 버튼으로 사이드바를 서랍처럼 열기
- 로그인·초대·재설정 화면: 사이드바 없이 짙은 보라 바탕 가운데 흰 카드

## 버튼 배치

| 위치 | 규칙 |
|------|------|
| 화면 머리 오른쪽 | 그 화면의 핵심 동작 1개를 주 버튼으로. 보조 이동(예: 실행 이력)은 테두리 버튼 |
| 화면 단위 수정·삭제 | 머리 오른쪽 끝 "⋯" 메뉴 안. 삭제는 구분선 아래 빨간 글자, 확인 창 필수 |
| 구획 머리 | 추가 동작은 제목과 같은 줄 오른쪽 테두리 버튼. 부수 동작(가져오기 등)은 글자 버튼 |
| 표의 행 | 연필·휴지통 아이콘 대신 행 끝 "⋯" 메뉴 하나. 이름 링크가 기본 동작 |
| 대화상자 | 오른쪽 정렬, 왼쪽 취소·오른쪽 확인 |

- "⋯" 메뉴 버튼의 접근 이름은 대상 포함 (예: "환경 self 작업")
- 파괴적 동작은 항상 메뉴 안쪽 마지막, 바로 누르는 버튼으로 두지 않음

## 모양

- 모서리: 버튼·입력칸 8px(`rounded-lg`), 카드·표 테두리 약 11px(`rounded-xl`), 배지 약 5px(`rounded-sm`, 상태 배지는 둥근 알약)
- 그림자: 떠 있는 요소(메뉴, 대화상자)에만. 카드는 테두리만
- 표: 머리 행은 옅은 보라 회색 바탕, 행 구분선 1px, 마우스 오버 시 바탕 강조
